# Measurement data

The `measurements/raw/` directory contains the original experimental acquisitions collected during system characterization.

The files are preserved in their original form. They were generated by different software iterations and therefore do not all share the same column names, units or metadata format. The MATLAB scripts used for interpolation and resistance analysis are in [analysis/matlab](../analysis/matlab/).

Generated logs and analysis outputs are excluded by the root `.gitignore`. Raw acquisitions are kept because they document the experimental work behind the project.
